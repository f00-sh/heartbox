# AGENTS.md — Heartbox

## Project name

**Heartbox** — hand-tinted Technicolor dark theme (one palette, many apps).

- Site: https://heartbox.f00.sh
- Repo: f00-sh/heartbox (org: **f00-sh**)
- Hub: https://f00.sh (product card after first release)

## Declared language

**Theme pack** (JSON/YAML/TOML/CSS + app-native config formats). No application backend. No package manager required.

- Canonical palette: `palette/heartbox.json` (also `.css` `.toml` `.yaml` `.scss`)
- Ports: `themes/<app>/` (generated by `scripts/generate-themes.py`)
- Product site: static `site/` (Cloudflare Pages)
- Python is allowed **only** for the generator and packaging helpers.

## Product laws

1. **One palette, many ports.** All app themes derive from `palette/heartbox.json`. Do not invent one-off hex values in ports.
2. **Feel over copy.** Warm hospital-night blacks, poppy red hero accent, verse-sky blue, cream foreground, **subtle silver metal** (cursor/chrome/punctuation). Not a cool-navy IDE theme.
3. **Silver is required.** Kurt-jacket cool metal `#B8C0C8` appears in every port that has a cursor or border token.
4. **Hub card on release.** First SemVer release earns a product card on https://f00.sh. Update card when copy or links change.
5. **Public copy is product-only.** Aesthetic inspiration only — no agent process, DNS wiring, or rights-holder drama on the site.
6. **Cloudflare is delivery.** Pages project `f00-heartbox` → `heartbox.f00.sh`. No GitHub Pages for product site.
7. **MIT.** No secrets in repo.
8. **Documentation pack** on every release (NASA SOP PDF, this-version memo PDF, CHANGELOG, README, Pages, man, file_id.diz).

## Layout

| Path | Role |
|------|------|
| `palette/` | Canonical color tokens |
| `themes/` | Per-app ports + `TEMPLATE.md` |
| `scripts/generate-themes.py` | Regenerate ports from palette |
| `site/` | Cloudflare Pages → https://heartbox.f00.sh |
| `wrangler.toml` | Pages project `f00-heartbox` |
| `docs/` | SOP seeds, Pages notes |
| `man/heartbox.1.md` | Man page |
| `file_id.diz` | Scene card |

## Edge (Cloudflare)

- **Pages project:** `f00-heartbox` → custom domain `heartbox.f00.sh`
- **Deploy:** push `site/**` → workflow `pages.yml`, or `npx wrangler pages deploy site --project-name=f00-heartbox --branch=main`
- **Account:** f00 Cloudflare (tj@f00.sh)

## Commands

```bash
# regenerate all ports from palette
python3 scripts/generate-themes.py

# open product site locally
# open site/index.html  or:
npx wrangler pages dev site --compatibility-date=2026-07-01
```

## Install channels

- Git clone / release tarball (theme files). No native binary.
- `scripts/install.sh` copies man page + points at themes.
- Package managers: none yet.

## Releases

- Every SemVer release: CHANGELOG, file_id.diz, README + docs triad, NASA SOP PDF, this-version NASA memo PDF, GitHub Release assets, f00 hub product card if first ship or copy change.
- Bump `version` in `palette/heartbox.json` and regenerate.
